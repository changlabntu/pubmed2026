# pubmed2026

Course material for a beginner LLM module: a literature review over PubMed
abstracts, built as a Streamlit app that students run and report on.

| Folder | What it is |
|---|---|
| `app/` | the current app (v3). Streamlit Community Cloud main file: `app/app.py` |
| `archive/module1-rag-v1/` | v1: keyword search with minsearch and one RAG call, Jupyter notebook |
| `archive/module1-rag-v2/` | v2: embeddings, fixed anchor + companions, grading, verification |

Keys needed: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`. See `app/README.md`.
